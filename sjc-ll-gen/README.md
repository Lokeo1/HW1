# Assignment 9: LLVM IR Generation

## Task

Your task is to generate LLVM IR for Static Java programs.

1. Complete the implementation of [src/main/java/sjc/llgen/LLVMIRGenerator.java](src/main/java/sjc/llgen/LLVMIRGenerator.java).
2. Ensure that your implementation passes the provided JUnit test cases in [src/test/java/sjc/test/LLVMIRGeneratorTest.java](src/test/java/sjc/test/LLVMIRGeneratorTest.java).

For LLVM IR syntax, refer to the official [LLVM Language Reference Manual](https://www.llvm.org/docs/LangRef.html). 

### Testing

Run the LLVM IR generator tests from the repository root:

```sh
sbt sjcLLGen/test
```

## Prerequisites

To run the tests, you need LLVM 23.1.0 or later installed on your system.
